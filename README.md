# Siete Raíces — Universo de cultivo

Plataforma oficial de exploración y documentación de un universo original de fantasía y cultivo.

## Estado
**Prototipo interactivo en desarrollo.** La experiencia incluye una escena 3D procedural, capítulos narrativos y un códice seleccionable de las siete raíces.

## Contenido previsto
- Enciclopedia de reinos, raíces, facciones, técnicas y personajes.
- Creación de cultivadores con linaje, procedencia y afinidades.
- Ceremonia de los Siete Juicios y compatibilidad con maestros.
- Misiones abiertas a discípulos e independientes.
- Herencias, secretos y encuentros con entidades del Abismo y del Caos.

## Desarrollo
- React 19
- TypeScript
- Vite
- CSS responsive

## Ejecutar localmente
```bash
npm install
npm run dev
```

## Principio central
Ningún personaje tiene garantizada la grandeza por su nacimiento, talento o maestro. Cada camino debe ganarse.
